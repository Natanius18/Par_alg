# Паралельнi алгоритми обчислювальної математики


### Для лаб 3, 4: [Microsoft MPI (MS-MPI)](https://www.microsoft.com/en-us/download/details.aspx?id=105289)

### Для лаби 3:
```
mpiexec -n 8 .\cmake-build-release\p3
```

### Для лаби 4:
```
mpiexec -n <PROCESS_NUM> .\cmake-build-release\p4 <POWER_OF_10_FOR_N>
```

Шлях до файлу також може відрізнятися.
